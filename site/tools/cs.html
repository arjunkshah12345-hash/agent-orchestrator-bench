Verdict

Strengths and weaknesses

Strengths

  • Single 4.8 MB binary, UI drawn in about 0.2 s, about 100 MB under load
  • Any CLI via profiles; resumes cleanly after tmux dies
  • Diff stats per session

Weaknesses

  • Profile config needed: -p alone was not picked up by the form in our run
  • No PR creation, review comments or remote features
  • Last release Aug 20, 2026
Evidence

What we saw and where it came from

Hands-on (this box)
Fully exercised via tmux key driving: 6/6 verified in each of 3 logged clean runs; crash isolation; restart recovery (paused + resumable).
Lane A, 3 runs
All 6 sessions created in 11.18 to 11.89 s (includes about 1.1 s per session of driver keystroke delays); 18/18 verified; peak RSS 102 to 118 MB.
Crash and merge
SIGKILL on one session: the other 5 stayed verified and partial work was preserved. Git merges: 5/6 clean, with t5b conflicting in shelf/config.py as designed.
Known issues
Observed: `-p/--program` flag was ignored by the new-session form when no profile existed (it still offered 'claude'); fixed by adding a profile. Error 'timed out waiting for tmux session' when the program is missing.
