About this benchmark

An independent look at the apps that run several coding agents in parallel with worktrees, sessions and review. Built from docs and feature testing, with the limits stated plainly.

FAQ

Questions

Who made this?

Arjun Shah ran the benchmark on 2026-10-19. Every number on this site comes from the logs under runs/ and the curated data file in the benchmark repo.

Is this a test of which tool writes the best code?

No. Code quality depends on the model and agent inside the orchestrator. We measured orchestration features and mechanics, and no real-model task runs feed the scores.

Why did real-model runs not happen?

No agent CLI was logged in on the box. A Groq free-tier key was tried through opencode, and 0 of 9 attempts passed because a single request exceeded the per-minute token limit.

Which tool is David Ondrej's?

Cloudroom (cloudroom.dev; davidondrej/cloudroom-core and cloudroom-gui, Apache-2.0). It scores 72.0 with 80% coverage. There is a public dispute on X between its maker and T3 Code's author; we cite neither side's claims as evidence.

Why is Orca's star count flagged?

GitHub reports about 97.9k stars, which is unusually high for a 7-month-old repo. We did not audit star provenance, and stars are only one input to the maturity criterion.

What does the dot in the table mean?

No evidence for that criterion. It is scored as a neutral 2.5, and the coverage column shows how much of the weight a score actually rests on.

Can I re-weight the scores?

The leaderboard shows four weight profiles. The raw criterion scores are in assets/data.json if you want your own.

Were any vendors paid or contacted?

No. Nothing was bought and no accounts were created.
